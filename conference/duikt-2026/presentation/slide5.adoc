= Слайд 5. Загальна схема системи
:duration: 40 с

== Текст

Ось загальна схема системи.

// Показати на верхню частину схеми.
Верхня частина — браузер на пристрої пацієнта.
Вебкамера знімає кисть, застосунок знаходить на зображенні 21 ключову точку, обчислює показники руху і передає їх у гру, яка дає візуальний і звуковий зворотний зв'язок.

// Показати на нижню частину схеми.
Нижня частина — сервер.
Туди надходять лише числові показники сеансу, які зберігаються в журналі сеансів.

У кабінеті фахівця з реабілітації ці дані можна переглянути, а звідти ж налаштувати вправи для конкретного пацієнта.

Пунктиром показано резервний режим для слабких пристроїв, про нього скажу наприкінці.
