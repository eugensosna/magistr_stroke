= Слайд 2. Проблема
:duration: 40 с

== Текст

Почну з проблеми.

Після інсульту чи травми найважче відновити саме дрібні рухи кисті: застебнути ґудзик, утримати ложку чи ручку.

Для України ця проблема загострилася через велику кількість бойових травм.

Відновлення потребує багатьох однотипних повторень, тобто регулярних щоденних тренувань.

Більшість цих повторень пацієнт може виконувати вдома, але там його не бачить фахівець з реабілітації.

Отже, фахівець не знає, чи виконувалася вправа і наскільки правильно.
