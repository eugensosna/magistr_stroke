# Написання тексту магістерської роботи

Тема: «Ігровий застосунок для дистанційної реабілітації пацієнтів з порушенням дрібної моторики на основі технологій комп'ютерного зору».
Загальні правила проєкту описано в `AGENTS.md`. Цей skill описує порядок роботи.

## Порядок роботи

1. **Контекст.** Прочитайте `AGENTS.md` (план і глосарій), цільовий файл у `chapters/` та розділ 1 (`chapters/10-chapter-1.adoc`).
   Розділ 1 фіксує мету, завдання й вимоги, і решта роботи має з ними узгоджуватися.
2. **План.** Перед написанням великого фрагмента (підрозділу або розділу) складіть план підрозділів і покажіть його користувачу, якщо зміст не був заданий явно.
3. **Джерела.** Кожне твердження про факти, статистику чи результати досліджень має спиратися на джерело.
   Щоб знайти й додати нове джерело, скористайтеся skill `thesis-sources`. **Не вигадуйте джерел і чисел.**
   Якщо підтвердження не знайдено, сформулюйте твердження обережніше або приберіть його.
4. **Написання** (формат описано нижче).
5. **Перевірка.** Запустіть `uv run build.py check`, потім `uv run build.py pdf` і перегляньте сторінки зі зміненим текстом (skill `thesis-review`).

## Формат AsciiDoc

```asciidoc
[[ch-model]]
== Назва розділу                       // РОЗДІЛ N, великими літерами, з нової сторінки

Вступний абзац розділу: що в ньому розглядається.

[[sec-model-metrics]]
=== Назва підрозділу                   // N.1

[[sec-model-metrics-angles]]
==== Назва пункту                      // N.1.1

Одне речення на рядок.
Наступне речення того самого абзацу.

Новий абзац після порожнього рядка.

[[sec-ch2-conclusions]]
=== Висновки до розділу 2

. Перший висновок.
. Другий висновок.
```

- **Переліки.** Маркований перелік (`* пункт;`) дає «–», нумерований (`. пункт;`) дає «1)».
  Пункти починаються з малої літери і закінчуються «;», останній закінчується «.».
- **Виділення.** Курсив пишеться `_текст_`, напівжирний `*текст*`. Напівжирним виділяють лише назви пунктів у вступі («*Актуальність теми.*»).
- **Посилання.** Рисунки, таблиці й формули згадуються до місця, де вони розташовані: `наведено на рис. <<fig-x>>`, `у табл. <<tbl-x>>`, `за формулою <<eq-x>>`.
- **Цитування** пишеться `<<id>>` або `<<id,с. 15>>`. Його ставлять у кінці речення перед крапкою: `... доведено <<laver2020>>.`
- **Скорочення.** Якщо скорочення трапляється в тексті понад двічі, додайте його до `chapters/02-abbreviations.adoc`. При першій згадці наведіть повну форму.
- Рисунки, таблиці та формули оформлюються за skill `thesis-figures`.

## Стиль

- Пишіть безособово: «розглянуто», «запропоновано», «встановлено», «у роботі показано». Займенники «я» і «ми» не вживайте.
- Кожен абзац має розвивати одну думку: перше речення формулює тезу, далі йдуть аргументи й джерела.
- Терміни мають бути сталими, див. глосарій в `AGENTS.md`. Англійський термін подається в дужках лише при першій згадці.
- Числа пишуться з десятковою комою (`0,48`), відсоток через нерозривний пробіл (`38 %`), діапазони через тире без пробілів (`2017–2020`).
- Лапки використовуйте «ялинки», апостроф — `'` (у тексті), тире в реченні — ` — `.
- Уникайте:
  - русизмів («являється», «на протязі», «співпадати», «слідуючий»);
  - канцеляризмів («здійснювати реалізацію»);
  - порожніх фраз («у наш час», «як відомо»);
  - оцінок без підстав («найкращий», «революційний»).
- **Вступ** (МОН № 40) містить такі пункти: актуальність, мета і завдання (ті самі, що в 1.5), об'єкт, предмет, методи, наукова новизна, практичне значення, апробація, структура роботи.
- **Висновки роботи** відповідають завданням за порядком: один висновок на кожне завдання, з конкретними результатами (числа, порівняння).
- **Анотація** містить бібліографічний опис роботи, обсяг (сторінки, рисунки, таблиці, джерела), стислий зміст, від 5 до 15 ключових слів. Англійська версія (Abstract) повторює український текст.

## Обсяг

Орієнтовний обсяг основної частини магістерської роботи — 60–80 сторінок.
Розділ 1 займає 15–20 сторінок, розділи 2 і 3 — по 20–30 сторінок.
Поточний обсяг видно після `uv run build.py pdf` (`pdfinfo build/thesis-dev.pdf`).
